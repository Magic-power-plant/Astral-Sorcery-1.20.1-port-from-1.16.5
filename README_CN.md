## ✨ 模组简介

**《星辉魔法》(Astral Sorcery)** 是一款围绕**星能（Starlight）**与**星座（Constellations）**展开的经典 Minecraft Forge 魔法模组。

在静谧的夜空下仰望群星，通过望远镜描摹古老的星座轨迹；探索遍布世界的大理石学院祭坛遗迹，收集纯净的水晶石与星光能量；搭建宏伟的多方块祭坛，将自身与星座共鸣，解锁庞大而深邃的**星能力（Perks）**天赋树，施展来自群星的奇迹之力。

## 🌌 核心玩法特色

### 🔭 1. 观星与十六星座
- **16 个独特星座**：
  - **明亮级星座（5 个）**：*生息座 (Aevitas)*、*攻烈座 (Discidia)*、*甲御座 (Armara)*、*御虚座 (Vicio)*、*解离座 (Evorsio)*。
  - **暗淡级星座（7 个）**：*晶金座 (Mineralis)*、*圣芒座 (Lucerna)*、*时钟座 (Horologium)*、*南极座 (Octans)*、*牧夫座 (Bootes)*、*天炉座 (Fornax)*、*唤生座 (Pelotrio)*。
  - **朦胧级星座（4 个）**：*寒冰座 (Gelu)*、*疏尘座 (Ulteria)*、*振变座 (Alcara)*、*贪狼座 (Vorux)*。
- **夜空观测**：收集遗迹中的**星图（Constellation Paper）**，在夜晚依次使用手持**望远镜（Looking Glass）**、**天文望远镜（Telescope）**与**观星台（Observatory）**观测夜空，连线唤醒明亮、暗淡与朦胧星座，并将其记录于**星芒宝典（Astral Tome）**之中。

### 🏛️ 2. 多方块祭坛与星能网络
- **四阶合成祭坛**：从最初的**星辉合成台**起步，逐步收集大理石与炭黑大理石搭建壮观的多方块结构，升级至**星辉祭坛**、**天辉祭坛**乃至搭配**星辉转继器**的终极**五彩祭坛**。
- **聚星缸与星能注入器**：在**聚星缸（Lightwell）**中利用**海蓝宝石**或水晶石汲取**星能液（Liquid Starlight）**，辅以**纳星圣杯**储运流体，并通过**星能注入器（Starlight Infuser）**将澎湃的星能灌注至物品之中。
- **星能传输网络**：利用**聚能水晶**与**天辉聚能水晶**采集夜空星能，使用**连接器**将星能引导至**水晶透镜**与**水晶棱镜**构建星能无线传输网络，并为透镜安装**燃烧透镜**、**破坏透镜**、**生长透镜**、**抗拒透镜**、**伤害透镜**、**再生透镜**、**幽芒透镜**等彩色镜片。

### 🌟 3. 星座共鸣、仪式与星能力
- **共鸣祭坛（Attunement Altar）**：搭建开阔的**共鸣祭坛**，在夜空中完成仪式，将自身或水晶石与已发现的星座进行共鸣（还可利用**更替之星**或**灿芒之星**转换共鸣）。
- **星能力（Perk Tree）系统**：通过执行契合所属根源星座的行为获取经验（最高修炼至 30 级），在星盘上点亮**根源星能力**、**主要星能力**、**关键星能力**、**顿悟星能力**与**聚焦星能力**，在宝石镶嵌槽中嵌入**烈阳宝石**、**皎月宝石**或**天空宝石**，或使用**封禁印章**自由调整流派。
- **仪式基座（Ritual Pedestal）**：将**共鸣水晶石**或**共鸣天辉水晶石**置于**仪式基座**之上（可配合**仪式锚**迁移作用范围），激活覆盖大范围区域的强力仪式效果——如生息座的生命恢复与作物催熟、攻烈座的惩戒之域、晶金座的化石为矿或时钟座的方块刻加速。

### 💎 4. 水晶石培育与星辰奇物
- **深度水晶石属性**：开采并培育**水晶石**与**天辉水晶石**（通过**天辉水晶簇**生长），利用**星辉锭切削工具**等手段打磨其*尺寸*、*纯度*、*可塑性*以及*工具耐久*、*工具效能*、*仪式强度*、*仪式范围*、*聚能比率*与星座聚焦属性。
- **星杖与星斗披风**：锻造**共振星杖**、**辉光星杖**、**排列星杖**、**更替星杖**、**冲击星杖**、**越空星杖**以及**汇星/液华/穹域共振器**、**璀璨棱镜**等奇物，并身披共鸣星座神力的**星斗披风（Mantle of the Stars）**。
- **群星映射台、天辉星门与万象泉**：在**群星映射台（Refraction Table）**上用**蚀刻注星玻璃**将星座的强力附魔与**星之酿**药水效果映射至装备与书本；搭建**天辉星门（Celestial Gateway）**实现跨维度传送；或建造**万象泉（Fountain）**配合**纳耳狂曼引口**、**费萨利德引口**、**佩特幔提引口**抽取地底流体精华、束缚生物或采集矿物。

## 🚀 玩家新手入门指南

1. **寻找学院祭坛与水晶石矿石**：在世界中探索由白色大理石构成的**学院祭坛**神殿（内部宝箱可获得**星图**与**海蓝宝石**），并在河流沙岸采集**海蓝宝石砂岩**；在地下深处（临近基岩层）开采**水晶石矿石**（夜晚手持**共振星杖**行走时，地面会浮现发光的星能烟雾指示地底矿脉）。
2. **制作星辉合成台**：找到大型大理石神殿中央悬浮的**聚能水晶**，移除屋顶遮挡并在其下方放置一个原版工作台，当星光束照射在工作台上时，即可合成入门核心**星辉合成台**与**共振星杖**。
3. **查阅星芒宝典**：手持**星芒宝典**右键打开（按住 `Shift` 右键可将**星图**存入宝典），浏览“发现 → 探索 → 共鸣 → 星座 → 五彩 → 辉煌”各个研究章节、查看多方块结构的 2D/3D 建造投影与合成配方。

## 💻 本地运行与编译说明（仅限个人学习与私下自用）

鉴于原模组协议**严禁未经原作者授权分发编译后的 `.jar` 构建产物**，本仓库不提供任何公开构建包下载。若您希望进行技术学习或个人私下体验，请在本地自行运行或编译：

1. 确保本地已安装并配置 **JDK 17**。
2. 克隆本仓库至本地。
3. 直接启动开发环境客户端体验：
   ```bash
   ./gradlew runClient
   ```
   *（Windows PowerShell / CMD 下请执行 `.\gradlew.bat runClient`）*
4. 或在本地生成仅供个人私下使用的构建包：
   ```bash
   ./gradlew build
   ```
   > **再次提醒**：编译生成的 `build/libs/` 下的 `.jar` 文件**严禁上传、分享或分发给任何第三方或公共平台**。
